# DOSM Datathon 2026 Submission

This repository contains the submission files for the **DOSM Datathon 2026** by team **TheOutliers**.

## Repository Contents

*   **`TheOutliers_Datathon2026_Dashboard.zip`**: Contains the source files and assets for our interactive data dashboard.
*   **`TheOutliers_Datathon2026_Report.pdf`**: The comprehensive report detailing our methodology, insights, and conclusions.
*   **`TheOutliers_Datathon2026_Video.mp4`**: A 10-minute video presentation explaining our dashboard and key findings.

*Note: Large files like the `.mp4` video and the `.zip` archive are stored using Git Large File Storage (LFS).*
